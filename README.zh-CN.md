# Hypermaker 🧩

> Hypermaker 的中文入口：一个本地优先的节点画布，用于把相连想法编排成可检查的文本、图片、音频和视频产物。

[English](README.md) · [简体中文](README.zh-CN.md)

## 快速开始

需要 Node.js 20+、已认证的 Codex CLI 和本地浏览器：

```bash
npm install
npm run dev
```

打开 <http://127.0.0.1:8787>；运行 `npm test` 做确定性检查，浏览器环境可用时运行 `npm run test:e2e`。完整产品说明、架构、贡献和路线见 [英文 README](README.md)。

当前版本为 `0.1.0`，限制和证据见 [`docs/project-status.md`](docs/project-status.md)。欢迎 issue/PR；代理可以协助分诊、调查、测试、文档和已接受工作的实现，维护者负责审核与合并。许可证和社区政策以仓库文件为准。

# Security

Hypermaker runs Codex with local filesystem access and may execute generated scripts. Treat it as developer tooling, not an untrusted multi-user service.

Do not expose the development server to a public network. Review prompts, scripts, manifests, and artifacts before using them in production workflows.

To report a security issue, use a private GitHub Security Advisory or contact the repository maintainers directly. Please do not publish an exploitable issue before a fix is available.
